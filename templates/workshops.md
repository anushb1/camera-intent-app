# Workshop agendas — copy/paste

## A. Definitions workshop (~90 min)

**Goal:** One agreed “pilot basis” for revenue and margin; grain and period locked.

| Time | Topic | Owner |
|------|-------|-------|
| 0–10 | Objectives; pilot success metrics (draft) | SE |
| 10–40 | Walk through KPI dictionary draft: revenue → margin | Finance |
| 40–55 | Dimensions (region, ship mode, category, customer) | Data |
| 55–70 | Reconciliation: what we match to month-end | Finance + Data |
| 70–85 | Actions: edits to dictionary; data extract request | SE |
| 85–90 | Next meeting; owners | SE |

**Pre-read:** KPI dictionary v0, one-pager.  
**Output:** KPI dictionary v1 + written data request.

---

## B. Technical & security discovery (~90 min)

**Goal:** Landing zone, IAM, PII, path to spike and production-like access.

| Time | Topic | Owner |
|------|-------|-------|
| 0–10 | Architecture recap; environments | SE |
| 10–35 | Sources, cadence, existing ETL/ELT | Data platform |
| 35–55 | GCP: projects, VPC, Cloud SQL vs BigQuery, secrets | CE + Data |
| 55–75 | Security: classification, audit, SSO | Security |
| 75–90 | Actions: spike scope; security checkpoint date | SE |

**Output:** Spike checklist + security follow-ups.
